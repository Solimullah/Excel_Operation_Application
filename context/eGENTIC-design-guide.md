**Version 1.0 · June 2026**

Full branding material: [www.egentic.com/branding](https://www.egentic.com/branding)

## 1. Logo

### Variants
- **Word & Figure Mark** — the full logo (flower icon + "eGENTIC LEAD GENERATION" wordmark). This is the primary sender mark and should preferably be used on **light backgrounds**.
- **Figure Mark** (the "Flower") — can be used alone **only** when eGENTIC is already clearly established as the sender from context (e.g. it appears elsewhere in the same composition, or in the headline).

### Safe Zone & Minimum Size
- Minimum clear space around the logo (to any other element or the format edge) = **the height of the logo itself**.
- Minimum logo size: **6mm**.

### Logo Height by Page Size
| Page Size | Logo Height |
|---|---|
| 72×279mm | 9mm |
| DIN lang / A6 | 8mm |
| DIN A5 | 9mm |
| DIN A4 | 12mm |
| DIN A3 | 18mm |
| DIN A2 | 22mm |
| DIN A1 | 36mm |

### Misuse — Do NOT:
- Use drop shadows
- Use the 2-colour main logo on dark backgrounds
- Ignore/crowd the clear space
- Stretch or skew
- Rotate
- Remove the figure mark
- Use unspecified colors
- Outline elements

## 3. Typography

### Primary Typeface — Roboto
- **Headings:** Roboto Black
- **Subheadings & logo baseline:** Roboto Bold
- **Body copy:** Roboto Regular

### Substitute Typeface — Inter
- **Headings/Subheadings:** Inter Black
- **Body copy:** Inter Regular
- No other typefaces may be used or substituted beyond these two families.

### Fixed Font Sizes
| Style | Primary (Roboto) | Substitute (Inter) |
|---|---|---|
| Main Headline | 700 / 90px | 700 / 90px |
| Subheadline | 700 / 45px | 700 / 45px |
| Body text | 400 / 20px | 400 / 20px |

### Bullet Points
Nested hierarchy using arrow/chevron bullets in accent colors (orange → dark blue → light blue → yellow), stepping down through: Parent point → Sub point 1 → Sub point 2 → Sub point 3 → Sub point 4.

## 4. Icons
- Unique, dynamic icon style consistent with the brand aesthetic.
- Usable on both light and dark backgrounds.
- **Icons are the only brand element where gradients are permitted.**
- Always scale proportionally — preserve even stroke weights and correct aspect ratios.
- Source library: template folder.

---

## 5. Imagery Style
- Genuine, people-forward, technology-centric.
- Should reflect the global team and a hands-on approach.
- Imagery should feel human — turning abstract concepts/services into relatable visuals.
- Every image should serve a clear purpose (avoid generic stock filler).

---

## 6. Backgrounds & Pattern
- Inspired by the eGENTIC flower symbol; used as a subtle, abstract section/background element.
- Use **minimally and selectively**.
- Pattern is versatile and can morph per composition, but must maintain an aligned, grid-like structure overall.
- Construction notes: based on an X/Y module (with the pattern width equal to 2× Y from center), 1pt stroke thickness, aligned to the edge of the layout.
